# 普通人财务决策场景全景（第一步产出）

> 目标：穷举普通人在一生中会遇到的财务类决策，按用户场景整理，每个决策给出「二维决策矩阵」的变量设计与营销钩子，为后续 MVP 计算器立项提供候选池。
> 整理原则：先场景后产品，从"用户什么时候会纠结"出发，再倒推计算器形态。

## 域 1：资产与投资

### 场景 1.1 定投复利：开始定投晚一年，到底差多少？
- **用户场景**：25 岁上班族纠结"现在开始定投 vs 再等几年"；家长想给孩子展示"时间的力量"。
- **矩阵设计**：
  - 行：每月定投金额（500 / 1000 / 2000 / 5000 元）
  - 列：开始年龄（20 / 25 / 30 / 35 / 40 岁）
  - 单元格：60 岁时总资产（假设年化 8%）
- **输出结论**：资产金额（大字）＋"晚开始 5 年 ≈ 少赚 X 万"对比条。
- **营销钩子（陈锦初式）**：标题"25 岁开始定投和 35 岁开始，差距一辆车"；结果卡可晒："我 25 岁开始定投，60 岁有 XX 万"。
- **可复用模型**：FV 复利公式（月度定投年金终值）。

### 场景 1.2 躺平退休：我到底要多少钱才能不工作？
- **用户场景**：想提前退休/辞职休息的人，核心纠结"我的存款 + 我的开销 → 能撑多久"。
- **矩阵设计**：
  - 行：年度花费（5 / 10 / 15 / 20 / 30 万）
  - 列：初始本金（100 / 200 / 300 / 500 / 1000 / 2000 万）
  - 单元格：可持续年数 / "花不完"（4% 规则 + 年金公式）
- **输出结论**：年数或"花不完"（绿色）；低于 10 年标红警示。
- **营销钩子**："花不完"三个字的心理冲击 > "可持续 52 年"；配合"躺平需要多少钱"标题自带传播力。
- **注意**：必须标注假设（年化收益率、通胀），做"透明的简化"。

### 场景 1.3 资产配置：我的风险承受 × 投资期限，该股债怎么配？
- **用户场景**：手上有 10 万闲钱，不知道放多少在股票、多少在债券/存款。
- **矩阵设计**：
  - 行：投资期限（1 / 3 / 5 / 10 / 20 年）
  - 列：风险承受等级（保守 / 稳健 / 平衡 / 进取）
  - 单元格：建议股债配比（如"股 20% 债 80%"）＋预期波动区间
- **输出结论**：具体配比 + "最差年景会亏 X%"。
- **营销钩子**："你的钱怎么分，居然有标准答案"；对比条：全股票 vs 建议配比的回撤差距。
- **数据来源**：主流资产配置模型（如 100-年龄 法则升级版，股债预期收益/波动）。

### 场景 1.4 目标储蓄：想存到 X 万，每月该存多少？
- **用户场景**：想 3 年内存首付、5 年内存教育金，反推每月储蓄额。
- **矩阵设计**：
  - 行：目标金额（10 / 30 / 50 / 100 万）
  - 列：目标年限（1 / 3 / 5 / 10 年）
  - 单元格：每月需储蓄金额（含年化 3%/5% 两档）
- **输出结论**：月存金额（大字）＋"相当于每天少喝 X 杯奶茶"换算。
- **营销钩子**：换算句式（陈锦初方法论核心）——抽象数字变可感知行为。

### 场景 1.5 定投 vs 一次性：我有一笔钱，一把梭还是分批投？
- **用户场景**：年终奖/拆迁款到手，纠结一次性买入还是定投摊成本。
- **矩阵设计**：
  - 行：市场后续情景（单边上涨 / 震荡 / 先跌后涨）
  - 列：投资方式（一次性 / 12 期定投 / 24 期定投）
  - 单元格：期末总资产 + 最大回撤
- **输出结论**：三种方式在各情景下的优劣排名。
- **营销钩子**："同样的钱，不同的下场"；揭示定投不是万能、但回撤体验差异巨大。
- **依赖**：需要历史行情回测数据（可用沪深 300 历史区间）。

## 域 2：负债与债务

### 场景 2.1 信用卡最低还款陷阱：只还最低，多久能还清？
- **用户场景**：刷了信用卡还不上全款的人，以为"每月还一点总能还清"。
- **矩阵设计**：
  - 行：债务余额（1 / 3 / 5 / 10 万）
  - 列：年利率（12% / 15% / 18% / 24% / 36%）
  - 单元格：还清所需年限；还款额 ≤ 利息时显示"永不还清"（黑色/红色）
- **输出结论**："永不还清"或"X 年 + 总利息 XX 万"。
- **营销钩子**（P0 首选，视觉冲击最强）：5 万债务 18% 利率只还最低 → 30 年 + 利息超过本金。"很多人以为还了钱，其实在给银行打工。"
- **数学**：最低还款 = max(余额×1%-3%, 50 元)，月利息 = 余额×月利率。

### 场景 2.2 房贷提前还款：每月多还一点，省多少利息？
- **用户场景**：有房贷的人纠结要不要提前还、每月多还多少。
- **矩阵设计**：
  - 行：贷款余额（50 / 100 / 150 / 200 万）
  - 列：每月额外还款（0 / 500 / 1000 / 2000 / 5000 元）
  - 单元格：还清年限 + 总利息节省（万元）
- **输出结论**："每月多还 1000，30 年房贷缩到 23 年，省利息 XX 万"。
- **营销钩子**：杠杆效应可视化——一点额外还款换来年限大幅缩短（非线性）。
- **注意**：区分等额本息/等额本金，标注 LPR 假设。

### 场景 2.3 债务雪崩 vs 雪球：多笔债务先还哪笔？
- **用户场景**：同时背信用卡+消费贷+花呗的人，纠结还款策略。
- **矩阵设计**：
  - 行：每月额外还款（500 / 1000 / 2000 元）
  - 列：策略（雪崩法先高利率 / 雪球法先小余额）
  - 单元格：全部还清总月数 + 总利息
- **输出结论**：哪个策略更快更省，差额可视化。
- **营销钩子**："同样的钱，换个顺序，少还 X 万"。

### 场景 2.4 贷款对比：同样借 10 万，不同利率差多少？
- **用户场景**：消费贷/网贷比价，被"日息万分之五"之类话术忽悠。
- **矩阵设计**：
  - 行：贷款金额（3 / 5 / 10 / 20 万）
  - 列：实际年化利率（5% / 10% / 15% / 24% / 36%）
  - 单元格：3 年期总利息 + 月供
- **输出结论**："日息万分之五 = 年化 18.25%"换算 + 总利息大字。
- **营销钩子**：拆穿话术——"你以为的便宜，其实贵一倍"；换算句式核心场景。

### 场景 2.5 分期年化：分期免息真的免息吗？
- **用户场景**：网购/大件分期，被"0 费率"吸引。
- **矩阵设计**：
  - 行：分期金额（2000 / 5000 / 10000 元）
  - 列：分期期数（6 / 12 / 24 期）
  - 单元格：真实年化成本（手续费折算 IRR）+ 与理财收益对比
- **输出结论**："12 期 7.5% 手续费 ≈ 年化 13.8%"。
- **营销钩子**：反直觉冲击——"免息分期，银行赚得更多"。

## 域 3：养老规划

### 场景 3.1 养老储蓄：现在每月存多少，退休才够花？
- **用户场景**：30-40 岁开始思考养老，但不知道目标金额。
- **矩阵设计**：
  - 行：期望退休年花费（8 / 12 / 20 / 30 万）
  - 列：当前年龄（25 / 30 / 35 / 40 / 45）
  - 单元格：每月需储蓄额（假设退休年龄 60，年化 5%）
- **输出结论**：月存金额 + "早 5 年开始，每月少存 X"。
- **营销钩子**：时间复利教育 + 焦虑与掌控感并存（"现在知道，还来得及"）。

### 场景 3.2 退休提取率：退休后每年取多少安全？
- **用户场景**：退休/准退休者，怕花太快或太省，需确定提取率。
- **矩阵设计**：
  - 行：提取率（3% / 4% / 5% / 6% / 8%）
  - 列：退休资产（100 / 200 / 300 / 500 万）
  - 单元格：可持续年限（或 95% 成功率下年限）
- **输出结论**："4% 规则内安全，6% 以上 30 年内可能耗尽"。
- **营销钩子**：FIRE 社区天然传播；"每年多花 1%，风险翻倍"。
- **升级**：可做成功率（蒙特卡洛）版本。

### 场景 3.3 延迟退休：多干 5 年，多领多少？
- **用户场景**：纠结 60 还是 65 岁退休（考虑养老金领取、资产增长）。
- **矩阵设计**：
  - 行：退休年龄（55 / 60 / 65 / 70）
  - 列：退休时资产水平（200 / 500 / 1000 万）
  - 单元格：累计可领取总额（到 85 岁）+ 资产终值
- **输出结论**："晚 5 年退休，多领 XX 万"。
- **营销钩子**：人生选择题的"如果当初"变体。

### 场景 3.4 养老金替代率：退休后生活质量掉多少？
- **用户场景**：评估社保/企业年金够不够。
- **矩阵设计**：
  - 行：退休前月收入（1 / 2 / 3 / 5 万）
  - 列：替代率情景（40% / 60% / 80% / 100%）
  - 单元格：退休后月领金额 vs 缺口提示
- **输出结论**："以你现在的缴费水平，退休后大概只能维持 X% 的生活"。
- **营销钩子**：扎心文案——"你现在月薪 2 万，退休后可能只有 8 千"。

## 域 4：买房置业

### 场景 4.1 租房 vs 买房：住多久买房才不亏？
- **用户场景**：首付够与不够之间纠结的刚需族。
- **矩阵设计**：
  - 行：居住年限（3 / 5 / 8 / 10 / 20 年）
  - 列：房价年涨幅假设（0% / 3% / 5% / 8%）
  - 单元格：结论"租房划算 / 买房划算"（盈亏平衡点）
- **输出结论**：明确是/否 + "第 X 年回本"。
- **营销钩子**：破除直觉误区——"住 3 年就换，买房必亏"；陈锦初式"如果当初"——"如果 5 年前买房 vs 租房，现在差 X 万"。

### 场景 4.2 首付与月供：我的首付 × 贷款年限 → 月供压力
- **用户场景**：选房阶段计算能不能供得起。
- **矩阵设计**：
  - 行：首付比例（20% / 30% / 50% / 70%）
  - 列：贷款年限（10 / 20 / 30 年）
  - 单元格：月供金额 + 占收入比（结合月收入档）
- **输出结论**：月供大字 + "月供占收入 X%（超过 50% 预警）"。
- **营销钩子**："你的月供，决定你敢不敢辞职"。

### 场景 4.3 利率选择：等额本息 vs 等额本金，总利息差多少？
- **用户场景**：办理房贷时银行让二选一。
- **矩阵设计**：
  - 行：贷款金额（100 / 200 / 300 万）
  - 列：还款方式（等额本息 / 等额本金）
  - 单元格：总利息 + 首月/末月月供
- **输出结论**："30 年下来等额本金省 XX 万，但前期月供高"。
- **营销钩子**：对比图天然适合分享。

### 场景 4.4 公积金 vs 商贷：同样贷款，利率差多少？
- **用户场景**：有公积金的人纠结组合贷比例。
- **矩阵设计**：
  - 行：贷款金额（50 / 100 / 150 / 200 万）
  - 列：贷款类型（公积金 / 商贷 / 组合贷）
  - 单元格：30 年总利息 + 月供
- **输出结论**："公积金贷款 30 年比商贷少还 XX 万"。
- **营销钩子**：白捡的钱——"你不用的公积金，等于每年白扔 X 千"。

## 域 5：保险配置

### 场景 5.1 保额测算：家庭支柱该买多少保额？
- **用户场景**：上有老下有小，怕出事拖垮家庭。
- **矩阵设计**：
  - 行：家庭年支出（10 / 20 / 30 / 50 万）
  - 列：需保障年限（5 / 10 / 20 年）
  - 单元格：建议保额（年支出 × 年限 + 负债缺口）
- **输出结论**："你的家庭需要 XX 万保障"。
- **营销钩子**：责任可视化——"你的命，值多少"（严肃向但强共鸣）。

### 场景 5.2 产品匹配：我的年龄 × 健康状况 → 该优先买哪类
- **用户场景**：想买保险但面对医疗险/重疾/寿险/意外险不知所措。
- **矩阵设计**：
  - 行：年龄区间（25 / 35 / 45 / 55）
  - 列：健康状况（健康 / 有慢性病 / 有既往史）
  - 单元格：推荐优先级（"首选重疾+医疗 / 注意健康告知 / 可能拒保"）
- **输出结论**：明确"首选/次选/谨慎"。
- **营销钩子**："25 岁买和 45 岁买，差的不只是保费"。

### 场景 5.3 返还型 vs 消费型：保险选哪个不吃亏？
- **用户场景**：被"不生病钱退回来"吸引，纠结返还型。
- **矩阵设计**：
  - 行：保障期限（20 / 30 年 / 终身）
  - 列：产品类型（返还型 / 消费型 + 差额自行投资）
  - 单元格：总保费 + 30 年后资金对比（消费型差额按 4% 复利）
- **输出结论**："返还型多交的钱，自己投资反而多 XX 万"。
- **营销钩子**：戳穿"返还"话术——"保险公司用你的钱赚两遍"。

## 域 6：教育与自我投资

### 场景 6.1 教育金：孩子 18 岁前要准备多少？
- **用户场景**：孩子刚出生，想规划教育金。
- **矩阵设计**：
  - 行：教育目标（国内本科 / 国内+硕士 / 出国本科 / 出国硕士）
  - 列：孩子当前年龄（0 / 3 / 6 / 10 岁）
  - 单元格：每月需储蓄额（到 18 岁）
- **输出结论**：月存金额 + "越早开始，压力越小"。
- **营销钩子**："孩子 0 岁开始存 vs 10 岁开始存，差 XX 万"。

### 场景 6.2 技能投资回收期：这笔学费几年赚回来？
- **用户场景**：想报培训班/考研，纠结投入值不值。
- **矩阵设计**：
  - 行：学费/投入（1 / 3 / 5 / 10 万）
  - 列：预期薪资涨幅（+2000 / +5000 / +10000 元/月）
  - 单元格：投资回收期（月数/年数）
- **输出结论**："3 万学费，月薪涨 5000，8 个月回本"。
- **营销钩子**：教育投资的"回本思维"——学技能像做投资一样算账。

### 场景 6.3 学历 vs 技能：两条路哪个划算？
- **用户场景**：纠结读研 vs 直接工作学技能。
- **矩阵设计**：
  - 行：路径（读研 / 直接工作 / 工作+在职读）
  - 列：行业薪资起点（5000 / 10000 / 20000）
  - 单元格：30 岁时的累计收入差
- **输出结论**："读研 3 年 vs 工作 3 年，35 岁前累计差 X 万"。
- **营销钩子**："如果当初读研/没读研"——陈锦初式人生后悔计算器。
